# cool-physics

Простой 2D-симулятор физики на C. Вся физика считается в **`long double`**
(80-битная расширенная точность на x86-64; в `float`/`double` значения
конвертируются только на границе рендера). Окно и ввод — **GLFW**, отрисовка —
**OpenGL**.

## Возможности

- Два режима симуляции, выбираются флагом при сборке:
  - `const` — постоянная гравитация: шарики одинакового размера падают в коробку со стенками;
  - `newton` — ньютоновская гравитация: шарики одинакового размера взаимно притягиваются (задача N тел, без центрального солнца).
- Интерактивное редактирование сцены в обоих режимах (`const` и `newton`):
  - **Создание новых шариков** мышью или с клавиатуры;
  - **Перемещение / бросок шариков** перетаскиванием мыши;
  - **Удаление шариков** по одному, проведением зажатой ПКМ или полная очистка сцены.
- Столкновения «каждый с каждым» — наивный проход по всем парам **O(N²)**
  (позиционная коррекция + импульс вдоль нормали с реституцией).
- Ньютоновская гравитация — тоже O(N²): `F = G·m₁·m₂ / r²` для каждой пары,
  с Пламеровским сглаживанием от сингулярности при `r → 0`.
- Интегрирование: полуявный (симплектический) Эйлер, фиксированный шаг 1/240 c.

## Сборка

Нужны: компилятор C11, dev-пакет GLFW 3 и заголовки OpenGL.

```bash
# Debian / Ubuntu
sudo apt install build-essential libglfw3-dev libgl1-mesa-dev
# Fedora
sudo dnf install gcc make glfw-devel mesa-libGL-devel
# macOS
brew install glfw
```

```bash
make            # соберёт ОБА бинарника
make const      # только постоянная гравитация -> bin/cool-physics-const
make newton     # только ньютоновская          -> bin/cool-physics-newton
make clean
```

Флаг `SIM=const|newton` (по умолчанию `const`) управляет тем, какой
`-DSIM_CONSTANT` / `-DSIM_NEWTON` передаётся компилятору.

## Запуск

```bash
make run                  # SIM=const по умолчанию
make run SIM=newton       # ньютоновская гравитация

bin/cool-physics-const  -n 200 --seed 42 --scale 1.5
bin/cool-physics-newton -n 300
```

| Опция        | Значение                           |
|--------------|------------------------------------|
| `-n N`       | количество шариков                 |
| `--seed S`   | сид RNG для сцены                  |
| `--scale X`  | начальный масштаб времени          |
| `-h`         | справка                            |

## Управление

### Мышь

| Действие                          | Результат                                              |
|-----------------------------------|--------------------------------------------------------|
| `ЛКМ` по шарику + перетаскивание  | Захватить и переместить (или бросить) шарик            |
| `ЛКМ` по пустому месту            | Создать новый шарик в точке курсора (и сразу двигать)  |
| `СКМ` (колёсико)                  | Создать новый шарик в точке курсора                    |
| `ПКМ` (клик или удержание)        | Удалить шарик под курсором                             |

### Клавиатура

| Клавиша                   | Действие                                               |
|---------------------------|--------------------------------------------------------|
| `N` / `+` (`=`)           | Создать новый шарик в позиции курсора                  |
| `X` / `Del` / `Backspace` / `-` | Удалить шарик под курсором (или последний шарик) |
| `C`                       | Очистить сцену (удалить все шарики)                    |
| `Space`                   | Пауза / продолжить                                     |
| `R`                       | Перегенерировать сцену                                 |
| `↑ / ↓`                   | Ускорить / замедлить время                             |
| `V`                       | Показать / скрыть векторы скоростей                    |
| `G`                       | Включить / выключить стенки                            |
| `Esc` / `Q`               | Выход                                                  |

Статистика (fps, число столкновений, модельное время) печатается в терминал.

## Структура проекта

```
Makefile                    # флаг SIM=const|newton -> -DSIM_CONSTANT / -DSIM_NEWTON
app.h                       # состояние приложения App и константы режимов
main.c                      # CLI, окно GLFW, главный цикл
util/
  rng.h / rng.c             # генератор случайных чисел xorshift64*
  color.h / color.c         # палитра цветов HSV -> RGB
physics/
  vec2.h                    # тип phys_real (long double) и 2D-векторная математика
  body.h / body.c           # структура Body, инициализация шарика и hit-test
  physics.h / physics.c     # мир World, шаг симуляции, добавление/удаление/выбор тел
  gravity.h / gravity.c     # постоянная и ньютоновская O(N^2) гравитация
  collisions.h / .c         # наивные O(N^2) столкновения
scene/
  scene.h / scene.c         # генерация начальных сцен, спавн и удаление шариков
input/
  input.h / input.c         # управление мышью и клавиатурой
render/
  gl.h / gl.c               # тонкая обёртка над OpenGL (fixed pipeline)
  camera.h / camera.c       # камера (letterbox) и перевод координат экран -> мир
  render.h / render.c       # отрисовка мира, шариков, выделения и скоростей
```

## Про точность

Все физические величины (координаты, скорости, силы, импульсы) хранятся и
обрабатываются в `long double`. На x86-64 Linux это 80-битный формат
расширенной точности (64-битная мантисса) — почти вдвое больше значащих цифр,
чем у `double`.

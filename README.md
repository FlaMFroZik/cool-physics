# cool-physics

Простой 2D-симулятор физики на C. Вся физика считается в **`long double`**
(80-битная расширенная точность на x86-64; в `float`/`double` значения
конвертируются только на границе рендера). Окно и ввод — **GLFW**, отрисовка —
**OpenGL**.

## Возможности

- Два режима симуляции, выбираются флагом при сборке:
  - `const` — постоянная гравитация: шарики падают в коробку со стенками;
  - `newton` — ньютоновская гравитация: солнце + планеты на круговых орбитах.
- Столкновения «каждый с каждым» — наивный проход по всем парам **O(N²)**
  (позиционная коррекция + импульс вдоль нормали с реституцией).
- Ньютоновская гравитация — тоже O(N²): `F = G·m₁·m₂ / r²` для каждой пары,
  с Пламеровским сглаживанием от сингулярности при `r → 0`.
- Интегрирование: полуявный (симплектический) Эйлер, фиксированный шаг 1/240 c.

## Сборка

Нужны: компилятор C11, dev-пакет GLFW 3 и заголовки OpenGL.

```bash
# Debian / Ubuntu
sudo apt install build-essential libglfw3-dev libgl1-mesa-dev
# Fedora
sudo dnf install gcc make glfw-devel mesa-libGL-devel
# macOS
brew install glfw
```

```bash
make            # соберёт ОБА бинарника
make const      # только постоянная гравитация -> bin/cool-physics-const
make newton     # только ньютоновская          -> bin/cool-physics-newton
make clean
```

Флаг `SIM=const|newton` (по умолчанию `const`) управляет тем, какой
`-DSIM_CONSTANT` / `-DSIM_NEWTON` передаётся компилятору.

## Запуск

```bash
make run                  # SIM=const по умолчанию
make run SIM=newton       # ньютоновская гравитация

bin/cool-physics-const  -n 200 --seed 42 --scale 1.5
bin/cool-physics-newton -n 300
```

| Опция        | Значение                                   |
|--------------|--------------------------------------------|
| `-n N`       | количество тел (в `newton` — число планет) |
| `--seed S`   | сид RNG для сцены                          |
| `--scale X`  | начальный масштаб времени                  |
| `-h`         | справка                                    |

## Управление

| Клавиша  | Действие                          |
|----------|-----------------------------------|
| `Space`  | пауза                             |
| `R`      | перегенерировать сцену            |
| `↑ / ↓`  | ускорить / замедлить время        |
| `V`      | показать векторы скоростей        |
| `G`      | включить/выключить стенки         |
| `Esc`/`Q`| выход                             |

Статистика (fps, число столкновений, модельное время) печатается в терминал.

## Структура проекта

```
Makefile                # флаг SIM=const|newton -> -DSIM_CONSTANT / -DSIM_NEWTON
main.c                  # окно GLFW, главный цикл, генерация сцен
physics/
  physics.h / physics.c # мир, тела, гравитация, интегрирование (long double)
  collisions.h / .c     # наивные O(N^2) столкновения
render/
  render.h / render.c   # World -> примитивы, камера
  gl.h / gl.c           # тонкая обёртка над OpenGL (fixed pipeline)
```

## Про точность

Все физические величины (координаты, скорости, силы, импульсы) хранятся и
обрабатываются в `long double`. На x86-64 Linux это 80-битный формат
расширенной точности (64-битная мантисса) — почти вдвое больше значащих цифр,
чем у `double`.
